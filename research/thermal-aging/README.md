# EQ 열적노화 연구 노트

보수성 확보와 Arrhenius 불확실성의 영향을 하나의 연구 프로젝트로 다룬다. #01만 작성 완료, #02~#18은 학습 개요다. 완료 표시는 연구 결론의 확정을 뜻하지 않는다.

## 운영 방법

- `_data/thermal_aging.json`의 status를 예정 → 진행중 → 완료로 변경하면 Index에 반영된다.
- #02 이후는 `_pages/research-study/NN.md`에 작성한다. 포스트로 발행할 때 그 파일을 `_posts/YYYY-MM-DD-eq-thermal-aging-NN.md`로 **이동**하고 permalink와 study_number를 유지한다. 동일 URL 파일을 두 개 남기지 않는다.
- 카테고리의 글 수는 발행 포스트만 센다. 17개 학습 개요는 Index에서 찾는다.
- references는 출처·판본·접근범위, notes는 공부 메모, data는 공개 수집표, analysis는 재현 절차, bibliography는 BibTeX를 관리한다.
- 이 폴더는 공개 저장소에 올라갈 수 있다. 내부 절차·고객 자료·제품/프로젝트 식별번호·사내 기준·유료 전문은 저장하지 않는다. 비밀을 숨기는 폴더로 사용하지 않는다.
- 근거 분류: 규정 요구 / 문헌 결과 / 연구 가설 / 확인 필요. DOI와 조항번호는 직접 확인 전 생성하지 않는다.

## 다음 글 #02 준비

1. eCFR 10 CFR 50.49 원문에서 적용범위, 노화, 여유도 문장을 직접 확인한다. 현재 자동 열람이 제한되어 조항 확정을 보류했다.
2. NRC 목록에서 RG 1.89 Rev.2 본문을 확보하고 적용 표준, 보충조건, 이전 판본 차이를 확인한다.
3. IEEE 323-2003과 IEC/IEEE 60780-323-2016의 관계를 확인한다. 특정 설비에 적용되는 판본은 별도 조사한다.
4. IEEE 101-1987의 Inactive-Reserved 상태를 명시하고 열수명 통계 참고자료 역할을 확인한다.
5. KEPIC END 세부 코드·판본·대응표준·국내 적용 근거를 적법한 자료로 확인한다. 미국 규정에서 KEPIC으로 이어지는 의무 체계를 가정하지 않는다.
6. 규격조사 CSV에 확인한 조항과 접근 제한을 기록한다.
