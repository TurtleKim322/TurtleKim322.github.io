이번 단계에서는 결과를 만들지 않는다. #06~#08의 단일 변수 예제 이후 #16에서 Python으로 10,000회 이상의 Monte Carlo를 수행한다.

기록 항목: 입력 CSV 해시/출처, 모델식, 단위, 종말점, 분포 선정 근거, 상관/공분산, 물리적 범위, 고정 변수, 난수 시드, Python 및 라이브러리 버전, 반복 수, 수렴성, 실행 명령.

출력 계획: Histogram, Mean, Median, 5/95 percentile, P(L≥Design Life), 민감도 도표. 평균 신뢰하한은 별도 추정하며 표본 5백분위수로 대체하지 않는다. SF 1.5/2/3은 가상 비교값이며 규격 요구값이 아니다. 통계 결과만으로 검증수명이나 규제 적합성을 확정하지 않는다.
