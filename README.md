## 프로젝트와 연재

### 🛰️ 서울 Sentinel-1 PS-InSAR 분석

서울 지역의 Sentinel-1 자료로 PS-InSAR 분석을 진행하며, 관심 영역과 데이터 준비부터 처리 중 발생한 문제, 간섭 위상과 PS 후보 확인까지 기록합니다. 분석 결과가 무엇을 보여 주는지, 아직 무엇을 판단할 수 없는지도 함께 살펴봅니다.

→ [연재 모아 보기](https://turtlekim322.github.io/insar-seoul/series/)

### 📡 Python SAR 시뮬레이터

가상의 점 표적에서 받은 신호가 SAR 영상으로 만들어지는 과정을 실험합니다. 거리 압축, 거리 이동 보정, 방위 압축의 결과를 그림으로 비교하고, 복소수 위상·정합 필터·도플러 등 필요한 수학을 연결해 설명합니다.
